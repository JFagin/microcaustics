# microcaustics notebooks

Start Jupyter from the package root after installing the notebook dependencies
below.

```bash
pip install -e ".[notebooks,science,macro]"
jupyter lab examples/notebooks
```

The complete collection uses `science` for astronomy and reference numerics.
It uses `macro` for the strong-lens renderer and therefore requires Python
3.11 or newer.

The distributed notebooks include their executed cell outputs so figures and
animations are visible on GitHub. Each performance-sensitive notebook prints
the runtime that produced its results. Each notebook generates its animations
and embeds continuous previews. When needed, previews are shortened without
changing resolution, cadence, or playback speed. Full animations are saved in
`assets/animations` and linked below each preview.
Every notebook must remain below 25 MB, including its embedded outputs.

The examples use fixed seeds for reproducibility.

The notebooks calculate their maps, sources, transfer functions, light curves,
and method schematics directly through the public `microcaustics` interface.
The Weisenbach IPM and SIM5 validation notebooks also read
reference results generated by those codes.

Centered square source-independent maps use `map_width_uas` and `map_pixels`.
The few explicit `PlaneGrid` objects occur in advanced method or validation
cells that require rectangular, off-center, or precisely aligned grids.

The first notebook reports the operating system, PyTorch/CUDA versions, GPU
model, first-call time, and warmed steady-state time. Its first-call number may
reuse an on-disk compiler cache and is therefore not described as pure compile
time.

Triton needs a writable compiler cache. Its ordinary user cache is normally
appropriate. On a managed system, set `TRITON_CACHE_DIR` to a writable local
directory before starting Jupyter. Do not place it on a slow network drive.

The Weisenbach-IPM and SIM5 notebooks are optional. To run those external
comparisons, set the reference-data paths with `MICROCAUSTICS_WEISENBACH_NPZ`,
`MICROCAUSTICS_WEISENBACH_FRAME_NPZ`, and `MICROCAUSTICS_SIM5_DIR`. They
explain what is being compared and stop cleanly when those files are absent.

## Suggested order

The source-model notebook `05_quasar_spectra_and_bandpass_photometry` includes
an unlensed spectrum baseline and a Q2237 image-B caustic-crossing GIF. It adds
static emission-line templates, intrinsic dust and intergalactic absorption to
the variable, microlensed Kerr continuum and integrates all six LSST responses.

The notebooks are grouped by topic below.

- `getting_started/00_static_maps_and_numerical_methods` combines runtime
  selection, separate first-call and warmed timings, IRS and IPM, and the scout/full/
  rectangle integration domains.
- `getting_started/01_q2237_production_light_curve_and_gif` is the primary
  end-to-end introduction. It creates a ten-year Q2237 image-B-like dynamic
  calculation with a full-Kerr disk, daily source variability, sparse maps,
  center labels, and a 147-frame GIF.
- `getting_started/02_dynamic_maps_and_light_curves` shows different map and
  source cadences, processing maps as they are generated, and saving selected maps.
- `methods/` covers stellar populations, exact nearby-star deflections, the
  Taylor approximation for distant stars, and caustics and their labels.
- `source_models/00_relativistic_disks_and_reverberation` combines the Kerr
  disk, variable-disk and transfer-function animations, and continuum
  reverberation with and without microlensing. The remaining source notebooks cover
  expanding supernovae, arbitrary custom sources, spectral microlensing, and
  selectable or user-defined viscous disk profiles.
- `workflows/` covers multi-image observations, strong-lens rendering,
  lensed-quasar simulations, streaming and export, and training-set generation.
  The observation examples use Rubin OpSim cadences. The dataset notebook
  generates independent single- and multi-image systems with fixed or sampled
  physical parameters and saves the results as separate files or a combined
  NPZ archive.
- `validation/` contains the independent Weisenbach and SIM5 comparisons,
  convergence/performance studies, and the analytic single-point-lens test.
- [`workflows/05_microimages_and_astrometry`](workflows/05_microimages_and_astrometry.ipynb) generates Q2237 B microimages, centroid
  motion, six-band light curves, caustic-crossing markers, and an animation.
  It uses the optional image callback and requires CUDA for its full example.
- `source_models/06_source_evolution_comparison` compares exact, linear,
  quadratic, and cubic source evolution. It includes full-spectrum
  timings and accuracy checks at three driving amplitudes.

The primary Q2237, end-to-end, streaming, and performance notebooks should be
run on CUDA before a performance-sensitive study. They select strict Triton
execution when available, print the detected device/backend, and retain an
explicit portable fallback for inspection on CPU-only systems.
